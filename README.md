# DAMSTOCK HOMES — Code Guide

Arabic walkthrough of the DAMSTOCK HOMES Flutter (Dart) source code, built with HTML, CSS and JavaScript.

- Every file of the project with its purpose
- Each class and function explained, linked to its line number
- `main.dart` explained line by line
- Glossary of the Dart / Flutter patterns used across the code
- Full source of all files with line numbers and syntax highlighting

Open `index.html` in any browser.

## Structure

```
index.html      Guide page with all the code
css/style.css   Styles (light and dark)
js/main.js      File search, line links and active-file highlight
```
